# 学生支援クエスト Webアプリ

## 概要
「学生支援クエスト：支援活動バッグでミッション突破！」の演習用Webアプリです。紙ベースの代替として、1チーム1端末で操作することを想定しています。

## ファイル構成
- index.html
- style.css
- script.js

## ローカルでの使い方
1. ZIPを展開します。
2. index.html をダブルクリックしてブラウザで開きます。
3. スマートフォンで確認する場合は、GitHub Pages等に公開してアクセスしてください。

## GitHub Pages公開手順
1. GitHubで新規リポジトリを作成します。
2. index.html, style.css, script.js をアップロードします。
3. Settings → Pages を開きます。
4. Branch を main、フォルダを /root にして保存します。
5. 表示されたURLを学生にQRコード等で共有します。

## 提出方法
結果画面で以下が可能です。
- 提出用テキストをコピー
- TXTファイルとして保存
- JSONファイルとして保存

Moodleやメールで提出する場合は、提出用テキストのコピーが最も簡単です。
